# Tisanovs_UnityUI
Ieskaite: "Darbs ar UI elementiem Unity dzinī"

Apraksts: Projekta ietvaros tika izstrādāta sākuma aina, no kuras lietotājs var izvēlēties uzsākt tēla veidošanas spēli
vai aizvērt aplikāciju. Tika nodrošināta iespēja pārslēgties starp abām projekta ainām. Tēla veidošanas ainā ir divi teksta
ievades lauki (Input Field), kuros lietotājs ievada tēla vārdu un dzimšanas gadu. Nospiežot pogu, teksta laukā tiek attēlots
ievadītais vārds un automātiski aprēķināts tēla vecums. Ar izkrītošā saraksta (Dropdown) palīdzību iespējams izvēlēties
vienu no vairākiem tēliem, kurus lietotājs var apģērbt. Projektā ir izveidotas vairākas apģērbu un aprīkojuma kategorijas.
Ir pievienoti skaņas efekti, tai skaitā pogu klikšķu skaņas, fona mūzika, kas uzlabo lietotāja pieredzi.Papildus ir izveidoti
divi Slider elementi. Viens no tiem ļauj mainīt izvēlētā tēla augstumu (garumu), bet otrs – tēla platumu.
